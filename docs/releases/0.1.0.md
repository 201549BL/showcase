Showcase's first release: a native Mac recorder and editor for product demos.

## Highlights

- Rounded floating recording bar with screen/window selection, microphone and camera previews, and a three-second countdown.
- Prominent Stop recording control and a menu-bar stop option.
- Liquid Glass editor on macOS 26, with translucent materials on older versions.
- Smoothed cursor motion, click animations, automatic screen zooms, and editable zoom sections.
- Face-camera visibility sections, mirroring, and size effects. Touching effects transition directly between sizes.
- Visible playback controls, scrubbing, trimming, and undo/redo.
- Local `.screenproject` files and 1080p/4K MP4 export.

## Install

Download `Showcase-0.1.0-universal.zip`, unzip it, and drag Showcase.app into Applications. The release app is Developer ID signed and Apple notarized.

Requires macOS 14 or newer. Supports Apple silicon and Intel. Microphone recording requires macOS 15 or newer; native Liquid Glass requires macOS 26.

Allow Screen Recording and Input Monitoring when prompted. Camera and microphone access are requested when enabled. If macOS asks for a restart after granting permissions, quit and reopen Showcase.

Existing recordings made with SmoothScreen can be opened directly. New recordings are saved in `~/Movies/Showcase`.
